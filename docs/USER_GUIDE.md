# User guide

1. Open Sources, enter a known source ID, or select Add a source.
2. To register, enter a public URL, unique ID, source description, optional context and watch items. Empty watch items trigger the contract defaults. Review carefully: URL and watch items cannot be edited later.
3. Connect a compatible wallet and switch to Studio Dev. Review the estimated fee and approve the wallet request. Track the submitted hash in Settings.
4. After finalized successful registration, open the source and create a baseline in a separate transaction. Manually run checks when needed.
5. Inspect the record history and change details. Older history beyond the 20 retained records cannot be recovered from the contract view.

The source owner alone may update, deactivate, create a baseline or run checks. A page cannot be reactivated with this contract's API. If transaction tracking times out, retain the hash and refresh tracking; do not blindly submit again.
