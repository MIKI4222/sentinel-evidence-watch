# Limitations and unverified features

- The provided repository/ZIP contained README and a root contract file only; referenced documentation and tests were missing. The user stated testing took place in Studio; this was not independently reproduced. A published finalized baseline transaction and live reads were verified separately.
- The deployed contract does not expose source-ID enumeration or global history. Local source IDs are only an index. Reports and activity are scoped to loaded IDs and retained records, never global.
- Only 20 latest records per source are retained; some older comparison values are unavailable. There is no scheduler, reactivation, or verified cross-contract integration. Page fetch uses HTTP GET and cleaned text is truncated at 12,000 characters. Studio Dev can reset.
- GenLayer public RPC returned HTTP 429 during rapid navigation tests; reads can fail or become stale until limits reset. The app uses in-flight deduplication, a short in-memory cache, bounded concurrency, and explicit retry/error states but cannot guarantee availability or overcome a shared upstream rate limit.
- Local unit tests cover registration input validation and basic transaction safety decisions only. Wallet signing, writes, execution-failure handling, timeout recovery, and classifications have not been end-to-end tested. No transaction was submitted during this implementation. The simulation of fee estimation was read-only.
- Transaction duplicate prevention is per browser's localStorage and does not coordinate across tabs or devices. If a submission fails before the hash is returned, the app cannot know if the transaction was sent. Check the wallet/explorer before retrying. Transaction hash history is lost if browser storage is cleared. Lifecycle stages are displayed as SDK-reported state/projection, not fabricated validator telemetry.
- The complete UI is not yet independently visually inspected in every state and viewport; accessibility and keyboard testing are incomplete. Large JS bundle receives a Vite size warning. Source directory and history support search/filter but not full pagination, alternate display modes or sorting controls. Registration navigates to the transaction tracker, not automatically to the source after finalization. This build is not production-certified.
